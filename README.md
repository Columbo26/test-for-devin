# Карта Королевства — мини-игра

Поле из 48 секторов (8 × 6), под которыми спрятана карта средневекового мира с дорогами, лесами и замками.

- 4 игрока: красный, синий, зелёный, жёлтый. Игрок, который открывает сектор, выбирается на панели слева.
- На каждом секторе написано, что на нём находится. Нажмите на сектор и подтвердите выбор: сектор переворачивается, показывает свой кусок карты и получает обводку цвета игрока.
- Игра заканчивается, когда открыты все секторы и карта видна целиком.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.

## Файлы

- `index.html`, `style.css`, `game.js` — игра (без зависимостей).
- `assets/map.svg` — карта мира.
